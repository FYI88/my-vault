# SEC-002 — CSP is strict on scripts but missing the hardening directives

> *This was generated by AI during triage.*

## Agent Brief

**Category:** bug
**Summary:** CSP is strict on scripts but missing the hardening directives

**Current behavior:**
The CSP meta tag sets `script-src 'self'` with no `unsafe-eval` — the part that matters most is right. The supporting directives are missing: no `object-src 'none'`, no `base-uri 'none'`, no `form-action 'self'`, no `frame-ancestors` (the app can be framed/clickjacked), and `style-src` carries `'unsafe-inline'` only to support static inline `style="..."` attributes in the HTML. `img-src` includes `data:` which nothing uses.

**Desired behavior:**
The policy hardens to: `default-src 'none'; base-uri 'none'; form-action 'none'; frame-ancestors 'none'; object-src 'none'; img-src 'self' blob:; media-src 'self' blob:; style-src 'self'; script-src 'self'`. The ~10 static inline `style="..."` attributes in the HTML are moved into classes so `style-src` can drop `'unsafe-inline'` entirely (all dynamic styling already goes through CSSOM, which CSP never blocks). The app must still load, render, search, play videos, and show thumbnails exactly as before.

**Key interfaces:**
- The CSP meta tag: the full directive set above.
- The stylesheet: new classes replacing the inline style attributes, with no visual change.
- The renderer: no functional changes; verify nothing depended on `data:` images or inline styles.

**Acceptance criteria:**
- [ ] The shipped policy contains `object-src 'none'`, `base-uri 'none'`, `form-action 'none'`, `frame-ancestors 'none'`, and `style-src 'self'` with no `unsafe-inline`.
- [ ] The app boots with zero CSP violations in the renderer console and all screens (welcome, create, seed, locked, unlocked, item, settings) render identically; video playback and thumbnails still work.
- [ ] Re-audit: the follow-up security-audit run marks this finding resolved in `findings.json`.

**Out of scope:**
- Changing the script-loading model, adding nonces, or touching crypto/file code.
