# Security Policy

## Supported Versions

This project is under active development. Security fixes are applied to the
latest code on `main`.

## Reporting a Vulnerability

If you discover a security issue, please report it privately.

- Preferred contact: open a private security advisory on GitHub (if enabled),
  or email the maintainer directly.
- Do not post exploit details in public issues before a fix is available.

Please include:

- A clear description of the issue
- Steps to reproduce
- Impact assessment
- Any proof-of-concept details needed to validate

## Response Process

- Initial acknowledgement target: within 72 hours
- Triage and validation: as quickly as possible
- Patch and coordinated disclosure: after a fix is ready

Thank you for helping keep My Vault users safe.
